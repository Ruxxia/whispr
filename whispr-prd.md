Build a modern social diary platform called “Whispr”.

Tech Stack:
- Next.js (App Router)
- TypeScript
- Supabase
- TailwindCSS
- Shadcn/UI
- Framer Motion

Core Vision:
Whispr is NOT a traditional social media app.
It is a safe emotional journaling platform where people share honest feelings through beautiful customizable diary papers.

The experience should feel:
- intimate
- aesthetic
- peaceful
- expressive
- premium
- emotionally safe
- highly immersive

Design Direction:
Create a highly aesthetic modern Gen-Z journaling platform inspired by:
- Pinterest
- Tumblr
- Japanese stationery
- cozy midnight journaling
- scrapbook culture
- analog diary aesthetics
- premium lifestyle apps

UI Style:
- minimalistic
- emotional
- warm
- soft gradients
- notebook/paper inspired
- subtle shadows
- rounded corners
- smooth animations
- beautiful typography
- glassmorphism only when needed
- clean spacing
- responsive pixel-perfect layouts

The application should feel:
- blazing fast
- premium
- calming
- addictive to customize
- emotionally expressive

VERY IMPORTANT:
The feed should NOT look like Twitter, Facebook, Threads, or Reddit.

Instead:
- every post feels like a real diary paper
- emotional storytelling first
- visual journaling experience
- cozy reading atmosphere
